## 🛒 Amazon Clone Website

A full-stack **Amazon Clone e-commerce website** built to recreate the core shopping experience of Amazon. The project includes a modern, responsive interface with product browsing, search, authentication, cart management, and order-related functionality.

### ✨ Features

* 🏠 Modern Amazon-style homepage
* 🔍 Product search and filtering
* 📦 Product listing and product details
* 🛒 Add to Cart / Remove from Cart
* 💳 Checkout and payment integration
* 🔐 User Registration & Login
* 👤 User account management
* 📱 Fully responsive design
* 📋 Order management
* 🖼️ Dynamic product images
* ⚡ Fast and interactive UI

### 🛠️ Tech Stack

**Frontend**

* HTML5
* CSS3
* JavaScript
* React.js
* Bootstrap / Tailwind CSS

**Backend**

* Node.js
* Express.js

**Database**

* MongoDB
* Mongoose

**Authentication & Payment**

* JWT Authentication
* Razorpay Payment Gateway

**Tools & Deployment**

* Git & GitHub
* Postman
* MongoDB Atlas
* Vercel / Render

This project helped me strengthen my understanding of **Full Stack Web Development**, REST APIs, database management, authentication, frontend-backend integration, and e-commerce application development.
